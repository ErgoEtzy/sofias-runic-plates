# Sofia's Viking-Age runic plates

An Obsidian-friendly set of notes for the 46 plates catalogued in Sofia Pereswetoff-Morath's *Viking-Age Runic Plates: Readings and Interpretations* (2019).

Start with [Index](<Index.md>).

## What is here

- one Markdown note per plate;
- short notes on rune forms and terminology;
- YAML properties for searching and sorting;
- a CSV export of the structured fields; and
- page references back to the book.

## Source book

Pereswetoff-Morath, Sofia. *Viking-Age Runic Plates: Readings and Interpretations*. Translated by Mindy MacLeod. Runrön 21 / Acta Academiae Regiae Gustavi Adolphi 155. Uppsala, 2019.

The source PDF is deliberately excluded from Git. Copyright in the book, its photographs, drawings, and original text remains with the relevant rights holders. These are independent research notes and are not affiliated with the author, publisher, or Uppsala University.

To use the page links locally, place a legally obtained copy named `Sofia_Pereswetoff_Morath_Viking_Age_Runic_Plates_Readings_and_Interpretations.pdf` in the repository root. 

## Obsidian

Open this folder as a vault, or place it inside an existing vault. The notes work without plugins. The optional queries in [Database fields and queries.md](<Database fields and queries.md>) use Dataview.
